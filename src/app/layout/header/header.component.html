Terminology Key terms used across the service
Job A container that groups one or more Queries and runs them together as a single batch you can track and review as a whole.
Query A single spatial comparison — an operator such as Intersects, Buffer or Nearest applied between your geometry and a Dataset.
Dataset A registered collection of geometries with a shared schema, sourced from an Oracle table — similar to what you'd know as a Layer.
Geometries The individual spatial records inside a Dataset — also commonly called Features (e.g. one field parcel, one licence boundary).
Category (of dataset) A theme label — Land, Water, Forestry, Livestock, Boundaries — used to group and filter Datasets and the Queries run against them.
